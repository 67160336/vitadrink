# VitaLife – Admin Dashboard (เฟส 6)

หน้าแดชบอร์ดแอดมินของร้านขายวิตามินและอาหารเสริม เป็น static site (HTML/CSS/JS ล้วน) ไม่ต้อง build

## มีอะไรบ้าง
- การ์ดตัวเลข: รายได้รวม, จำนวนคำสั่งซื้อ, คำสั่งซื้อที่รอดำเนินการ, จำนวนลูกค้า
- สรุปรายได้ 7 วัน / 14 วัน / รายสัปดาห์ (กราฟแท่ง + ตาราง)
- สินค้าใกล้หมด (สต็อก ≤ เกณฑ์ที่ตั้งไว้)
- คำสั่งซื้อล่าสุด 8 รายการ

## รันในเครื่อง
เปิด `index.html` ด้วยเบราว์เซอร์ หรือ `python3 -m http.server`

## Deploy ด้วย GitHub Actions
1. สร้าง repo แล้ว push โค้ดขึ้น branch `main`
2. ไปที่ **Settings → Pages → Build and deployment → Source** เลือก **GitHub Actions**
3. Push อีกครั้ง (หรือกด Run workflow ในแท็บ Actions) แล้วรอลิงก์ในขั้นตอน deploy

## เชื่อมข้อมูลจริง
แก้ `js/data.js` โดยแทนที่ `PRODUCTS`, `ORDERS`, `CUSTOMER_COUNT` ด้วยข้อมูลจาก API/ฐานข้อมูล
(โครงสร้างตรงกับหัวข้อที่ 6 ในแผน) ส่วน `js/dashboard.js` ไม่ต้องแก้

> หมายเหตุ: หน้านี้ยังไม่มีระบบล็อกอิน (เป็น static) หากเอาไปใช้จริงต้องมี middleware ตรวจสิทธิ์ role = admin ฝั่งเซิร์ฟเวอร์
